===============================================================
APDS-9930 PROXIMITY МОДУЛЬ (ESP32) - СПРАВКА
===============================================================

БИБЛИОТЕКИ (Менеджер библиотек Arduino IDE)
---------------------------------------------------------------
APDS9930          (Depau/SparkFun) - обязательно
Adafruit SSD1306  - только если DEBUG_OLED_RAW = 1
Adafruit GFX      - только если DEBUG_OLED_RAW = 1

ПОДКЛЮЧЕНИЕ
---------------------------------------------------------------
SDA -> GPIO 21
SCL -> GPIO 22
APDS-9930 и OLED на одной шине I2C
OLED адрес: 0x3C (если не находится - попробовать 0x3D)


НАСТРОЙКИ (в начале скетча)
---------------------------------------------------------------
SDA_PIN, SCL_PIN     Пины шины I2C (21 и 22)
SENSOR_PERIOD_MS     Период опроса датчика, мс (25 = ~40 Гц)

threshold1           Порог 1 (нижний), в единицах отфильтрованного RAW
threshold2           Порог 2 (верхний), в единицах отфильтрованного RAW
                     Это обычные int, можно менять прямо в программе
TH_HYST              Гистерезис порогов (8). Событие "упало ниже порога"
                     срабатывает при значении < порог - TH_HYST.
                     Защищает от дребезга на границе

DEBUG_SERIAL         1 = слать RAW в Serial Monitor / Plotter (115200)
                     0 = выключено, код не попадёт в прошивку
DEBUG_OLED_RAW       1 = показывать RAW и шкалу на OLED
                     0 = выключено, OLED-библиотеки не подключаются

OLED_RAW_MAX         Правый край шкалы на OLED (1023). Уменьшить, если
                     объект обычно далеко и шкала еле шевелится
OLED_ADDR            I2C-адрес OLED (0x3C)


ПЕРЕМЕННЫЕ ДЛЯ ВАШЕГО ПРОЕКТА
---------------------------------------------------------------
proxValue            Отфильтрованный RAW, 0..1023
over1                true, пока значение выше Порога 1
over2                true, пока значение выше Порога 2

События (true ровно один проход loop() в момент пересечения):
th1Rise              значение поднялось выше Порога 1
th1Fall              значение упало ниже Порога 1 (с учётом гистерезиса)
th2Rise              значение поднялось выше Порога 2
th2Fall              значение упало ниже Порога 2 (с учётом гистерезиса)

proxOk               true, если датчик найден и работает


ФУНКЦИИ
---------------------------------------------------------------
proxInit()           Вызвать один раз в setup()
proxUpdate()         Вызывать в loop() как можно чаще, без delay()


ВНУТРЕННИЕ ПЕРЕМЕННЫЕ И ФУНКЦИИ (не трогать)
---------------------------------------------------------------
apds                 Объект датчика
median5()            Медианный фильтр на 5 отсчётов (убирает выбросы)
MED_N, medBuf,
medIdx, medFilled    Данные медианного фильтра
proxEma              Сглаженное значение (адаптивный EMA)
tSensor              Таймер опроса датчика

Блок DEBUG: OLED
debugOledInit(), debugOledUpdate(), display, oledBar, tDraw

Блок DEBUG: SERIAL
debugSerialInit(), debugSerialUpdate(), tSerial


КАК РАБОТАЕТ ФИЛЬТР
---------------------------------------------------------------
1. Медиана из 5 отсчётов убирает одиночные выбросы
2. Адаптивный EMA: объект неподвижен - сильное сглаживание,
   резкое движение - быстрое слежение
   alpha = 0.05 .. 0.6
   (0.05 уменьшить до 0.03 - спокойнее, увеличить до 0.1 - живее)
3. Пороги с гистерезисом - нет дребезга событий


ДИАГНОСТИКА И ПОДБОР ПОРОГОВ
---------------------------------------------------------------
1. DEBUG_SERIAL = 1
2. Arduino IDE -> Инструменты -> Плоттер по последовательному порту
   (скорость 115200)
3. Линии в плоттере:
   raw       сырое значение датчика
   filtered  значение после фильтров (proxValue)
   th1, th2  текущие пороги
4. Поднести объект в нужные позиции, прочитать filtered,
   вписать в threshold1 и threshold2


КАК УБРАТЬ ДИАГНОСТИКУ В ГОТОВОМ ПРОЕКТЕ
---------------------------------------------------------------
Быстро: DEBUG_SERIAL 0 и DEBUG_OLED_RAW 0
Полностью: удалить блоки между метками
   DEBUG: OLED (НАЧАЛО БЛОКА) ... (КОНЕЦ БЛОКА)
   DEBUG: SERIAL (НАЧАЛО БЛОКА) ... (КОНЕЦ БЛОКА)
и вызовы debugSerialInit(), debugOledInit(), debugSerialUpdate(p),
debugOledUpdate() в proxInit() и proxUpdate() (они внутри #if)


ПРИМЕЧАНИЯ
---------------------------------------------------------------
- Если в проекте уже есть Wire.begin() или Serial.begin(),
  удалить их дубликаты из proxInit() и debugSerialInit()
- Не использовать delay() в loop(), иначе фильтр и события
  будут запаздывать. Использовать millis()
- APDS-9930 выдаёт силу отражённого ИК-света, а не расстояние.
  Значение зависит от размера и цвета объекта
- Если RAW упирается в 1023, можно снизить усиление и ток
  светодиода: apds.setProximityGain(PGAIN_4X),
  apds.setLEDDrive(LED_DRIVE_50MA). Пороги подбирать заново


ПРИМЕР ИСПОЛЬЗОВАНИЯ
---------------------------------------------------------------
void setup() {
  proxInit();
}

void loop() {
  proxUpdate();

  if (th1Rise) { /* сработал Порог 1 */ }
  if (th2Rise) { /* сработал Порог 2 */ }
  if (th1Fall) { /* упало ниже Порога 1 */ }
  if (over2)   { /* пока выше Порога 2 */ }
}
